Open GitHub Issues

What to include in a support request

  • Extension version and Chrome version.
  • A short description of what you expected and what happened.
  • Steps to reproduce the issue, if possible.
  • Screenshots with private information removed.

Do not post collected email lists, personal data, passwords, access tokens or other sensitive information in public issues.
