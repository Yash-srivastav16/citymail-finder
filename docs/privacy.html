CityMail Finder Privacy Policy

Last updated: 12 November 2026

This policy describes the current CityMail Finder browser extension. It must be kept in sync with every released build. If the product adds accounts, analytics, cloud storage, payments or another search provider, this policy and the Web Store disclosures must be updated before release.

Information processed

You may provide city names by typing them or importing a CSV/Excel file with a City column. You may configure a search query and the number of result pages. When you run the search workflow, the extension uses these inputs to construct Google Search requests.

The extension extracts email-shaped text visible in Google Search result pages. Result records include the email string, associated city, source page URL, source type and creation timestamp. Every extracted address is an unverified match. CityMail Finder does not verify email ownership, mailbox existence, deliverability, or whether an address belongs to the associated business. You must independently verify each address and its business association before relying on it or contacting anyone.

Google Search and third-party processing

The extension opens Google Search pages in your browser and automatically navigates through the configured result pages. Your browser sends those search requests to Google. Google may collect and process search queries, device/browser information and other data under Google's own terms and privacy policy. CityMail Finder does not control Google's data handling.

The extension reads visible text from Google Search result pages using its scripting permission. It does not crawl the linked business websites. Google may restrict automated queries or display CAPTCHA or other verification challenges. If a challenge appears, you must complete it yourself in the Google tab. The extension may resume after the challenge is cleared; if it remains paused, use Start / Resume. CityMail Finder does not automate, solve, bypass, or circumvent CAPTCHA or other access controls.

Local storage and data transmission

CityMail Finder stores collected result records in the extension's browser IndexedDB database. It stores city settings, search query, page-count setting and search-resume progress in browser local storage. The current extension code does not upload the collected email list or city list to a CityMail Finder server and does not require a CityMail Finder account.

When you export, the browser downloads an Excel file to a location you choose. The exported file is outside the extension's local database; protect it appropriately.

Permissions

  • tabs: open, monitor, update and close the Google Search tab used by the workflow.
  • scripting: read visible text from the Google Search result page to identify email-shaped strings.
  • unlimitedStorage: retain the local IndexedDB result collection without the usual extension storage quota restrictions.
  • https://www.google.com/search* host access: allow the extension to run its page-reading script on Google Search result pages.

The extension also uses browser local storage and IndexedDB within its own extension page. Review the shipped manifest and code for the exact permissions in a given release.

Sharing and sale

The current extension code does not sell or transmit the collected result list to CityMail Finder. Search requests are sent to Google by your browser as described above. Do not collect, export, disclose or use personal data in ways that violate applicable privacy, data protection, anti-spam or marketing laws.

Retention and deletion

City and query settings and collected results remain in the browser until you delete them using the controls in the extension or remove the extension and its data through Chrome. You can remove individual email records, delete all collected emails, or clear all saved data in the app. You are responsible for deleting exported files from your device when no longer needed.

Children

CityMail Finder is a business research tool and is not designed for children.

Changes to this policy

This policy may be updated when the extension's functionality or data handling changes. The latest version will be published on this page.

Contact and support

For questions or to report an issue, use the CityMail Finder GitHub Issues page.
